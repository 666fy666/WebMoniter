    Web 管理界面¶

    首次部署使用默认账号 admin、密码 123 登录；也可通过环境变量自定义初始凭据。登录后进入概览。界面使用粉紫光感、玻璃导航与清晰内容面，支持桌面侧栏和移动端底部导航。

    页面¶

    页面 用途
    概览 已启用任务、运行与排队数量、最近执行活动
    任务 搜索与筛选、最近结果、下次执行、立即运行、配置与日志入口
    监控数据 切换平台、分页和刷新；按需加载图片，支持原图预览
    配置 按业务模块编辑；多账号、推送渠道、时间与凭据输入
    日志 主日志或任务日志增量读取，可暂停；保留最近 2,000 行
    账户 密码修改、登出、主题、材质与动态效果

    任务提交立即返回排队状态，后台统一执行；重复点击复用已有执行记录。禁用任务会跳过，配置并启用后再运行。重启中断不会自动补跑，避免重复签到和推送。

    配置编辑¶

    每次保存只更新提交时的分区，其他分区及等待响应期间的新编辑会保留；离开页面或关闭标签前提示未保存内容。字段校验失败会显示路径并定位。若其他页面或任务已经更新文件，保存返回版本冲突，重新加载后再编辑。

    已保存的 Cookie／密码显示“已设置”，输入框保持空白。直接保存保留原值，使用清除操作才会删除；填写新值替换。账号排序不会把密码绑定到错误账号。MySQL 分区可测试尚未保存的连接设置。

    YAML 高级编辑需要明确确认，其中包含完整凭据；只在可信设备使用。完整 YAML 不存入 localStorage，退出编辑或离开页面即释放前端状态。Web 端口等启动参数修改后需重启，其余任务和数据库设置由配置监听热更新。

    外观与操作¶

    主题提供浅色、深色、跟随系统。效果提供自动、完整、简化；系统“减少动态效果”优先，触屏自动模式和不支持背景模糊的浏览器降级。导航、工具栏和弹层呈现玻璃高光，表单与日志强调可读性。系统光标保持原样。

    页面隐藏时暂停轮询及动画，重新可见后恢复；请求失败会逐步降低请求频率。支持键盘 Tab 导航、可见焦点和移动触控。会话默认有效 7 天，活动续期；修改密码后撤销其他登录会话。

    验证¶

    安装与自动检查命令统一见 开发指南。关键回归覆盖配置密钥与冲突、保存期间编辑、任务终态、日志与数据请求竞态、页面切换、图片预览和动态效果偏好。浏览器截图供人工观察，不再作为像素基线；本轮结果与历史性能数据分别见 审查报告。

    用户自测清单（真实账号操作会产生实际签到或通知，请使用自己的测试账号）：

    • 登录、刷新、重启后会话恢复；修改密码后其他设备退出，主动登出有效。
    • 多模块编辑、慢网保存时继续编辑或切换模块、密钥保持／替换／清除、账号重排；另开标签修改后出现冲突，YAML 修改与返回表单正常。
    • 启用／停用任务、手动执行、定时执行及重复提交；检查成功、部分成功、失败和重启中断，确认无重复推送。
    • 配置应用日志无持续重试错误；重复保存相同任务间隔不推迟下次运行。测试环境模拟清理失败后恢复，确认删除目标最终完成；失败期间再次保存应采用最新配置。
    • 已使用平台的动态／直播变化、首次快照、删除目标、图片下载；实际签到、验证码和推送渠道结果由真实服务确认。
    • 数据分页、刷新失败后保留旧数据；切换日志来源、暂停／恢复、日志轮转，隐藏标签后恢复读取。
    • 手机与平板、320 px 窄屏、横屏、软键盘：保存按钮可点击，导航不遮挡正文；检查主题、字体、长文本、连续滚动和图片缩放。
    • 系统减少动效开关即时生效；浏览器限速与 CPU 降速下观察加载反馈、首屏、布局跳动和交互延迟，不以单次实验室阈值替代实机体验。
    • 如使用 MySQL，在备份与测试实例上验证断线写入、恢复回放和镜像；生产规格做长期内存／浏览器进程观察。Windows、arm64、真实第三方平台不在本地模拟测试的保证范围内。
